# Result

**New `taurworks setup` command** (`src/taurworks/setup_command.py`,
wired via `src/taurworks/cli.py`): resolves the shell-helper and
`tl.source` target path via `$TAURWORKS_SHELL_HELPER_PATH` →
valid-absolute `$XDG_CONFIG_HOME` → `~/.config` fallback (mirroring
`global_config.py`'s existing `config_path()` precedence); writes both
files idempotently (`_write_if_changed`: created/updated/unchanged);
prints the exact `source` lines; never edits shell startup files;
truth-first summary matches `project refresh`'s existing convention.
Added `shell_resources.read_tl_source_text()` alongside the existing
`read_shell_helper_text()`.

**Fixed the refresh/setup path-drift gap** review flagged on the
planning PR (#84): `_tw_shell_refresh`'s `target_path` computation in
`src/taurworks/resources/shell/taurworks-shell.sh` now uses the
identical precedence, so a refresh after an XDG-based setup targets the
same file.

**New `scripts/install`**: derives the repo root the same way
`scripts/build`/`scripts/check-workflows` do, then runs a non-editable
`pipx install . --force && taurworks setup`.

**Tests:** new `tests/setup_command_test.py` (11 tests: resolution
precedence, idempotent re-run, content-matches-packaged-resources) and
`tests/cli_test.py::SetupCliTest` (3 tests: CLI end-to-end, default
path, XDG path, idempotent re-run). Found and fixed a latent gap in
`tests/shell_helper_test.py`'s existing
`test_tw_shell_refresh_uses_default_path_when_no_override`: it never
actually exercised the "no override at all" case, since the shared
`_subprocess_env()` helper sets `XDG_CONFIG_HOME` to an isolated dir by
default for other tests' isolation — the test happened to pass only
because the old code ignored `XDG_CONFIG_HOME` entirely. Explicitly
cleared it in that test to prove the true fallback case, and added
`test_tw_shell_refresh_uses_xdg_config_home_when_no_override_path`,
`test_tw_shell_refresh_ignores_relative_xdg_config_home`, and
`test_setup_then_shell_refresh_target_same_file` (the integration test
this WI's acceptance criteria explicitly require).
