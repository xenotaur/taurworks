## 2024-05-18 - [Critical Sentinel Vulnerability]
**Vulnerability:** Argument Injection risk in `subprocess.run` command for `conda create` in `src/taurworks/manager.py`. The `packages` variable (which can originate from user input via `--packages` CLI argument) is naively split by commas and directly appended to the `conda create` command arguments list. A malicious user can pass a package list like `requests,-c,malicious_channel,malicious_package` or `--prune,--json` which would be interpreted by `conda` as options rather than package names, potentially leading to arbitrary package installation from untrusted sources or altering command behavior in dangerous ways.
**Learning:** Argument injection occurs even without `shell=True` when untrusted input is passed to an executable that interprets those inputs as flags (e.g. anything starting with `-` or `--`).
**Prevention:** Always validate user input passed to command-line tools. When passing dynamic strings that should strictly be treated as positional arguments (e.g. package names), either validate that they don't start with `-` or use a tool-specific separator like `--` if supported, though `conda` does not officially support `--` to delimit options from packages. The safest approach is validating each package name against a regex for valid package names (alphanumeric, dashes, underscores, dots, etc.).
