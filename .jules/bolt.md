## 2024-07-06 - Optimizing Directory Size Calculation
**Learning:** Using `os.walk` in conjunction with `os.path.isfile` and `os.path.getsize` results in multiple redundant `stat` system calls for each file. This creates a significant performance bottleneck when computing total sizes for large project directories. `os.scandir` caches these attributes and speeds up the traversal and size calculation significantly.
**Action:** Always prefer `os.scandir` over `os.walk` when calculating directory sizes or iterating through files where file types and attributes are needed.
## 2024-09-21 - Optimizing iterdir with scandir
**Learning:** Using `pathlib.Path.iterdir()` inherently causes redundant stat system calls when we subsequently check for `is_dir()`. However, we must be careful with imports. If we replace it with `os.scandir()`, we must ensure that `os` and `pathlib` are imported. Also, applying filters (e.g., `is_dir`) before sorting the list reduces operational complexity and increases performance further.
**Action:** Always prefer `os.scandir` over `pathlib.Path.iterdir()`. Ensure correct imports (`os`, `pathlib`) are present when refactoring. Filter before sorting where applicable.
